# ProMarket – כל מומחיות, קריאה אחת

**במקום לחפש בגוגל – פותחים קריאה קלה ומקבלים הצעות ממקצוענים.**
מרקטפלייס פתוח (בסגנון Marketplace של פייסבוק / יד 2) שבו כל מי שיש לו מומחיות – טכנאי מחשבים, אינסטלטור,
מורה פרטי, מנהל חשבונות – מוריד אפליקציה, רואה קריאות פתוחות ומרוויח כסף.

## איך זה עובד
1. **הלקוח פותח קריאה**: תחום, תיאור קצר, ואיך לטפל – 🏠 אצלי / 💻 מרחוק / 📞 בטלפון.
2. **הקריאה נשלחת למקצוענים מתאימים**: בתחום, פנויים, עם קרדיט. בעבודה "אצלי" – רק ברדיוס שלהם;
   מרחוק / בטלפון – מכל הארץ.
3. **מקצוענים שולחים הצעות** (מחיר, זמן, הודעה). שליחת הצעה עולה קרדיט לפי התחום – כך המערכת מרוויחה. עד 5 הצעות לקריאה.
4. **הטלפון של הלקוח מוסתר** – אלא אם סימן "מותר להתקשר אליי". הלקוח רואה את כל ההצעות עם דירוג ויכול לבחור בלי לדבר עם אף אחד, או להתקשר למי שהוא רוצה.
5. **הלקוח בוחר הצעה** → פרטי הקשר נפתחים למקצוען הנבחר.
6. **העבודה**: המקצוען מעדכן סטטוס ומתעד (טקסט + תמונות). אצל הלקוח: בדרך → בעבודה → סיום + חתימה. מרחוק/טלפון: בטיפול → סיום.
7. **תשלום** – הלקוח בוחר מראש:
   - **ישירות למקצוען** (מזומן/ביט/העברה) – המערכת הרוויחה כבר מעלות ההצעה.
   - **באפליקציה (מאובטח)** – הכסף נגבה כשבוחרים הצעה, מוחזק, ומשתחרר רק אחרי שהלקוח מאשר סיום. המערכת שומרת 12% עמלה.
8. **דירוג הדדי**.

## מבנה
| תיקייה | מה יש |
|---|---|
| `backend/` | שרת Node.js (ללא תלויות) – כל הלוגיקה העסקית + REST API + טסטים |
| `backend/public/index.html` | אפליקציית/אתר הלקוח – פתיחת קריאה, קבלת הצעות, בחירה, אישור סיום, לוח קריאות |
| `android-pro/` | אפליקציית אנדרואיד למקצוען (Kotlin) – פיד, זמינות, שליחת הצעה, חיוג וניווט Waze |

קטגוריות (`backend/src/categories.js`): מחשבים, אינסטלציה, חשמל, שיפוצים, מנעולנות, מיזוג, הובלות, ניקיון,
שיעורים, ייעוץ מקצועי, ו"אחר – כל מומחיות". לכל תחום: מחיר הצעה, איפה אפשר לבצע את העבודה (אצל הלקוח, מרחוק או בטלפון), ודרישת מסמך
(רישיון / ביטוח / היעדר רישום פלילי) שאדמין חייב לאשר לפני שהמקצוען מקבל קריאות.

## הרצה
```bash
cd backend && npm test   # 12 טסטים
npm start                # http://localhost:3000  (ממשק הלקוח)
```
אנדרואיד: לפתוח את `android-pro/` ב-Android Studio (האמולטור פונה ל-`10.0.2.2:3000`).

## השלבים הבאים
1. Postgres + PostGIS במקום הזיכרון; נעילת מונה ההצעות עם `SELECT … FOR UPDATE`.
2. OTP ב-SMS + JWT (היום המשתמש מזוהה ב-header `x-user-id` – לא לפרודקשן!).
3. העלאת תמונות אמיתית (S3) + צ'אט בתוך הקריאה.
4. FCM, מפה, CameraX, מסכי Onboarding, עבודות פעילות וארנק באנדרואיד.
5. סליקה אמיתית (כרטיס / Google Pay / Bit) דרך ספק תשלומים ישראלי עם תמיכה ב-Escrow/פיצול תשלום.
6. דשבורד אדמין ואפליקציית לקוח נייטיב.
