# ProMarket – כל מומחיות, קריאה אחת

**במקום לחפש בגוגל – פותחים קריאה ומקבלים הצעות.** מרקטפלייס פתוח שבו כל מי שיש לו מומחיות נרשם בדקה ומרוויח:
טכנאי מחשבים, אינסטלטור, סוכנת נסיעות, מורה, מי שמרכיב רהיטים. חברות מפרסמות מלאי (מלונות, אטרקציות, מוצרים)
דרך ה-API שלנו, וכל סוכן יכול למכור אותו עם רווח משלו.

📄 **האפיון המלא: [`docs/PRD.md`](docs/PRD.md)** – כולל מודל הכנסות, נסיעות, רגולציה ומס, אמון ובטיחות וסדר עבודה.

## מה עובד היום
- **כניסה ב-SMS** (קוד חד-פעמי + טוקן חתום). הרשמה בצעד אחד, **30 ₪ קרדיט מתנה**, חבר מביא חבר.
- **קריאות והצעות**: אצל הלקוח / מרחוק / בטלפון. הטלפון של הלקוח מוסתר עד שהוא מאשר.
- **תשלום**: ישירות למקצוען, או באפליקציה (מוחזק עד אישור הלקוח, 12% עמלה).
- **תיעוד עבודה**, סטטוסים, חתימה, דירוג הדדי.
- **נסיעות ומלאי ספקים**: מתאמים ל-RateHawk (מלונות) ול-Duffel (טיסות) + **API לספקים שלנו**.
  מחיר = נטו + תוספת פלטפורמה + רווח הסוכן; הסוכן לא רואה את הנטו; המחיר נבדק מחדש מול הספק לפני חיוב.
- **רישיונות**: תחומים מפוקחים נחסמים עד שאדמין מאשר מסמך.

## מבנה
| נתיב | מה יש |
|---|---|
| `backend/src/marketplace.js` | קריאות, הצעות, הפצה גיאוגרפית, ארנק, escrow, הפניות |
| `backend/src/auth.js` | OTP ב-SMS וטוקנים |
| `backend/src/catalog.js` | תמחור ומכירת מלאי ספקים (תוספות, מט"ח, בדיקת מחיר, הזמנה) |
| `backend/src/partners.js` | ה-API לספקים (מפתחות API, מוצרים, מלאי, הזמנות) |
| `backend/src/providers/` | מתאמים: `ratehawk.js`, `duffel.js`, `mock.js` |
| `backend/public/index.html` | אתר הלקוח (`/`) |
| `backend/public/pro.html` | אתר המקצוען/הסוכן (`/pro`) – הרשמה, פיד, הצעות, חיפוש במלאי, עבודות |
| `android-pro/` | אפליקציית אנדרואיד למקצוען (Kotlin) – כניסה ב-SMS, פיד, הצעות, חיוג, Waze |

## הרצה
```bash
cd backend
npm test        # 24 טסטים
npm start       # http://localhost:3000 (לקוח)  ·  http://localhost:3000/pro (מקצוען)
```
במצב פיתוח קוד ה-SMS מודפס בטרמינל ומוזן אוטומטית במסך, ויש ספקים מדומים (`mock-hotels`, `mock-flights`).

| משתנה סביבה | למה |
|---|---|
| `NODE_ENV=production` | מבטל קודים בתגובה וטעינת קרדיט בלי סליקה |
| `AUTH_SECRET` | חובה בפרודקשן – חתימת טוקנים |
| `ADMIN_PHONES` | טלפונים של אדמינים, מופרדים בפסיק |
| `RATEHAWK_KEY_ID`, `RATEHAWK_API_KEY`, `RATEHAWK_BASE_URL` | מלונות (RateHawk) |
| `DUFFEL_TOKEN` | טיסות (Duffel) |

אנדרואיד: לפתוח את `android-pro/` ב-Android Studio (האמולטור פונה ל-`10.0.2.2:3000`).

הנתונים נשמרים בזיכרון, ה-SMS והסליקה מדומים, והמתאמים ל-RateHawk/Duffel נכתבו לפי התיעוד אך **טרם נבדקו מול ה-sandbox שלהם**.
ראו סעיפים 9, 12 ו-13 ב-[`docs/PRD.md`](docs/PRD.md).
