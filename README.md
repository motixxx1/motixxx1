# ProMarket – מרקטפלייס קריאות לבעלי מקצוע

"Uber לבעלי מקצוע": לקוחות פותחים קריאה, אינסטלטורים/חשמלאים/מנעולנים/רצפים תופסים אותה בתשלום.

## מבנה
| תיקייה | מה יש |
|---|---|
| `backend/` | שרת Node.js (ללא תלויות) – כל הלוגיקה העסקית + REST API + טסטים |
| `backend/public/index.html` | אפליקציית/אתר הלקוח – לוח קריאות בסגנון יד 2 + פתיחת קריאה |
| `android-pro/` | אפליקציית אנדרואיד לבעל המקצוע (Kotlin) – פיד, זמינות, תפיסה, ניווט Waze |

## מה כבר מומש (לפי האפיון)
- **עץ קטגוריות היררכי** עם דרישת רישיון/ביטוח/רישום פלילי ומחיר ליד לכל תחום.
- **חסימת תחומים מורשים** עד שאדמין מאשר מסמך (`/api/admin/...`).
- **Geo-Push Dispatcher** – התראה רק לבעלי מקצוע פנויים, בתחום, ברדיוס שלהם, ועם קרדיט.
- **Pay-Per-Lead** – הקריאה מוצגת בלי טלפון/כתובת; פתיחה מחייבת קרדיט; מקסימום 3 תופסים ואז נסגרת.
- **ארנק** – טעינה, חיוב לידים, היסטוריה (ledger).
- **עמלת הצלחה (Escrow)** – 12% נשמרים, השאר משוחרר אחרי אישור הלקוח.
- **מחזור חיי עבודה** – בדרך → בעבודה (תמונות לפני) → סיום (תמונות אחרי + חתימה) → דירוג הדדי.

## הרצה
```bash
cd backend && npm test   # 7 טסטים
npm start                # http://localhost:3000  (ממשק הלקוח)
```
אנדרואיד: לפתוח את `android-pro/` ב-Android Studio (האמולטור פונה ל-`10.0.2.2:3000`).

## השלבים הבאים
1. Postgres + PostGIS במקום הזיכרון, נעילת claim עם `SELECT … FOR UPDATE`.
2. OTP ב-SMS + JWT (היום המשתמש מזוהה ב-header `x-user-id` – לא לפרודקשן!).
3. FCM, מפה, CameraX, מסכי Onboarding וארנק באנדרואיד.
4. סליקה אמיתית (כרטיס / Google Pay / Bit) דרך ספק תשלומים ישראלי.
5. דשבורד אדמין ואפליקציית לקוח נייטיב.
